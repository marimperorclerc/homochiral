Python codes for drawing Tile(a,b) and the spectre tiling in .svg graphics.

It can generate so far:

* clusters of Tile(a,b)
* substitution patches for Tile(1,1)==spectre tile  

### References
Code is based on the drawsvg package: 

    https://pypi.org/project/drawsvg/

And the python code for the spectre tiling with alternate chirality for substitution rules:

    https://github.com/shrx/spectre/blob/master/spectre.py

Related paper 'Chasing rotational symmetry in the spectre tiling' (Sept 2026) is available on arXiv:

    https://arxiv.org/abs/2609.07592
